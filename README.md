Feedstock for [troll](https://www.roma1.infn.it/~bonvini/troll/) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

TROLL: threshold (large-x) resummation to N3LL' for Drell-Yan (mass and rapidity), DIS and Higgs

## Architectures

| Architecture | Latest published |
|--------------|------------------|
| linux-amd64 (`linux-64`) | ✅ `3.3` |
| linux-arm64 (`linux-aarch64`) | ✅ `3.3` |

_As of the last feedstock render; the badges above are live._


## Install

```bash
conda install -c hep-forge -c conda-forge troll
```
